# CreditWise

### Intelligent Loan Approval & Risk Prediction System

## Overview

CreditWise is a Machine Learning-based system
designed to predict loan approval outcomes by
analysing applicant financial, personal, and
credit-related information.

## Problem Statement

Traditional loan verification processes can be
time-consuming and inconsistent. CreditWise aims
to assist loan officers by predicting loan
approval outcomes using historical applicant data.

## Tech Stack

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
